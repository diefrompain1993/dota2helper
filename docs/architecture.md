# Архитектура системы: GSI + OCR

## Цель
Внешнее приложение, которое получает данные о герое игрока через Game State Integration, извлекает информацию о вражеских героях и их предметах через захват экрана и распознавание иконок, а затем формирует рекомендации по сборке предметов.

## Основные компоненты
1. **Модуль GSI (Game State Integration)**
   - Локальный HTTP-сервер (Flask/FastAPI) на порту 4000–5000.
   - Принимает JSON от Dota 2: имя героя, предметы, состояние (уровень, здоровье и т.д.).
   - Хранит актуальное состояние в памяти или кэше.

2. **Модуль захвата экрана (Screen Capture)**
   - Периодически делает снимок экрана областей, где видны портреты врагов и их предметы (верхняя панель, scoreboard по TAB).
   - Использует `mss` или `pyautogui`.

3. **Модуль распознавания (OCR / Icon Recognition)**
   - На вход получает фрагменты скриншота; на выходе — список вражеских героев и их предметов.
   - Реализация через template matching (OpenCV) с иконками из `assets/heroes/` и `assets/items/`.
   - Возвращаемая структура:
     ```json
     {
       "enemy_heroes": ["axe", "lion", "shadow_fiend"],
       "enemy_items": {
         "axe": ["blink_dagger", "blade_mail"],
         "lion": ["blink_dagger", "aether_lens"]
       }
     }
     ```

4. **Модуль рекомендаций (Rule-based)**
   - Входные данные: герой игрока, его предметы, враги и их предметы.
   - База знаний с тегами героев и контр-предметами; простые правила для подбора рекомендаций и пояснений.

5. **UI-модуль**
   - Отдельное окно (PyQt/Tkinter или веб-интерфейс) с отображением врагов, их предметов, предметов игрока и рекомендованного билда.

6. **Общий менеджер / главный цикл**
   - Периодически обновляет состояние из GSI, делает скриншот, распознаёт, обновляет рекомендации и UI.

## Поток данных
1. Dota 2 → GSI сервер (`http://localhost:<port>`) сохраняет данные о герое игрока.
2. Приложение снимает экран HUD/scoreboard → модуль распознавания определяет врагов и их слоты.
3. Модуль рекомендаций получает `my_hero`, `enemy_heroes`, `enemy_items`, текущее снаряжение игрока и предлагает предметы с пояснениями.
4. UI отображает рекомендации в реальном времени.
